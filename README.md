# The Bloomy Residences — Interactive Airbnb Showcase

An interactive, front-facing architectural web experience for **The Bloomy Residences** in Mar Mikhael, Beirut, Lebanon (hosted by Superhost Dalloul on Airbnb).

## Features
- **6-Floor Beaux-Arts Facade**: Scaled architectural elevation view as if standing directly in front of the building.
- **Dynamic Cursor Lighting**: Windows illuminate with an authentic warm golden glow as the mouse moves across floors.
- **Apartment Window Highlighting**: Hovering over any window illuminates all windows associated with that apartment.
- **Double-Tap / Double-Click Lightbox**: Double-clicking or double-tapping any window opens a high-resolution photo gallery showcasing that apartment.
- **8 Real Apartments Mapped to Exact Floors**:
  - **Floor 1**: The Bloomy 1 (Ground Floor & Entrance)
  - **Floor 2**: The Bloomy 2
  - **Floor 3**: The Bloomy 3 & The Bloomy 4
  - **Floor 4**: The Bloomy 5
  - **Floor 5**: The Bloomy 6 & The Bloomy 7
  - **Floor 6**: The Bloomy 8 (Penthouse Arched Windows)
- **Direct Airbnb Booking**: Seamless "Book on Airbnb" CTA button directly linked to each room's official listing.
- **Zero Heavy Dependencies**: Lightweight, performant pure HTML5, CSS3, and modern Vanilla JS (~300 lines total).
